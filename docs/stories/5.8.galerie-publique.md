# Story 5.8 : Galerie publique de la collection

## Status

Draft

## Story

**As a** visiteur,
**I want** voir à quoi ressemblent les cartes,
**so that** j'aie envie de participer.

## Acceptance Criteria

1. Une page publique montre le catalogue des cartes publiées.
2. Elle ne révèle **aucune donnée personnelle** ni aucune collection individuelle.
3. Elle est indexable et sert d'argument à l'inscription.
4. Elle fonctionne sans compte.

## Tasks / Subtasks

- [ ] Page publique (AC: 1, 3, 4)
- [ ] Absence de données personnelles (AC: 2)

## Dev Notes

**Priorité S : elle sert la collecte, pas le jeu.** À faire quand les visuels existent —
une galerie de silhouettes grises n'attire personne.

### Testing

- Vérifier qu'aucune collection individuelle n'est atteignable depuis cette page.
