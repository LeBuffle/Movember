# Story 8.6 : Gestion des équipes par l'administrateur

## Status

Draft

## Story

**As a** bénévole de l'organisation,
**I want** créer une équipe pour une entreprise et lui désigner un capitaine,
**so that** un employeur puisse inscrire ses salariés sans que je passe par la base.

## Acceptance Criteria

1. L'administrateur crée une équipe d'entreprise ou d'association (FR78).
2. Il relève son code d'adhésion pour le transmettre.
3. Il désigne le capitaine parmi les membres.
4. Chaque geste est journalisé.

## Tasks / Subtasks

- [ ] Vérifier la création d'équipe par l'administrateur (AC: 1, 2)
- [ ] Vérifier la désignation du capitaine (AC: 3, 4)

## Dev Notes

⚠️ **Cette story est déjà livrée** par la story 7.2 : `/admin/equipes` porte la création
d'équipe, le relevé du code et la désignation d'un capitaine, avec journalisation.

Elle reste listée parce que l'epic 8 la revendique. Son périmètre réel est une
**vérification à deux comptes**.

### Testing

- Créer une équipe d'entreprise, relever le code, la rejoindre avec un compte de test,
  puis désigner ce compte capitaine.
