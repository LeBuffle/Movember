# Story 7.8 : Fil d'actualité et publication depuis le back-office

## Status

Draft

## Story

**As a** administrateur,
**I want** publier un message aux participants depuis mon téléphone,
**so that** le mois soit animé sans passer par un développeur.

## Acceptance Criteria

1. L'administrateur publie un message avec **texte et image**, depuis son téléphone.
2. Le fil est visible par les participants dans l'application.
3. Un message peut être **épinglé** en tête de fil.
4. Un message publié peut être modifié ou dépublié.
5. Chaque publication est journalisée.
6. Un fil vide se dit, plutôt que d'afficher une page blanche.
7. Publier ne déclenche **pas** automatiquement une notification : les deux sont des
   gestes distincts.

## Tasks / Subtasks

- [ ] Table `news_posts` et ses règles d'accès (AC: 2, 3)
- [ ] Écran de publication avec image (AC: 1, 4, 5)
- [ ] Affichage du fil (AC: 2, 6)

## Dev Notes

**Le fil est le canal calme** ; la notification est le canal qui interrompt. Les lier
automatiquement transformerait chaque petite annonce en interruption — et c'est ainsi qu'on
fait couper les notifications.

**Depuis un téléphone**, parce que c'est là que l'animation se fera : dans un train, entre
deux réunions.

Le téléversement d'image réutilise le stockage posé à la story 5.6.

### Testing

- Publier depuis un téléphone, avec une photo.
- Épingler, modifier, dépublier.
