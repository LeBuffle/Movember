# Story 7.9 : Page dédiée d'équipe

## Status

Review

## Story

**As a** membre d'une équipe,
**I want** une page qui montre où en est mon équipe,
**so that** on se motive entre nous.

## Acceptance Criteria

1. Chaque équipe a une page dédiée : membres, progression, classement (FR77).
2. Les membres y figurent par leur **pseudonyme**.
3. La page est atteignable depuis le classement d'équipe.
4. Le capitaine y retrouve le code d'invitation ; les autres membres non.
5. Une équipe qui vient d'être créée affiche un état de départ, pas une page vide.

## Dev Agent Record

### Décisions prises

**Le code d'invitation ne vient jamais de la page, il vient de mon adhésion.** L'équipe est
lue par la vue `public_teams`, qui **ne porte pas la colonne du code** ; le code affiché est
celui que `ownTeam()` me renvoie, et uniquement si je suis le capitaine de cette équipe-là.
Autrement dit, il n'existe aucun chemin par lequel cette page pourrait révéler le code
d'une autre équipe, même en cas d'erreur d'affichage. C'est la même raison qu'à la story
7.1 : la RLS filtre des lignes, pas des colonnes.

**L'adresse est le slug, pas l'identifiant.** `/jeu/equipe/les-moustachus` se lit à voix
haute dans un couloir ; un UUID ne se lit pas.

**Les membres sont désignés par leur pseudonyme.** Aucune adresse e-mail n'est lue par la
page — testé.

**Une équipe qui vient d'être créée dit qu'elle est vide.** « Personne n'a encore rejoint »
plutôt qu'une liste d'un seul nom sans explication : le capitaine vient précisément de la
créer et cherche quoi faire ensuite, donc le code d'invitation est là, juste à côté.

**Le rang vient du classement d'équipe, pas d'un second calcul.** La page réutilise
`getTeamLeaderboard` : une équipe sous le seuil de membres n'y figure pas, et la page le
dit au lieu d'afficher un rang inventé.

**La page est atteignable depuis le classement d'équipe** — chaque ligne du classement
pointe vers `/jeu/equipe/<slug>`, ce qui est la façon dont on tombe sur l'équipe d'un
collègue et dont on a envie de la rejoindre.

### Ce que cette story ne fait pas

- **Pas de page publique hors connexion.** Comme le fil, c'est réservé aux participants :
  une page d'équipe indexée exposerait des pseudonymes et des chiffres sans raison.
- **Pas de photo ni de description d'équipe.** Cela demanderait un téléversement, une
  modération et un stockage de plus, pour un usage incertain.
- **Pas de classement interne à l'équipe.** Classer ses propres collègues entre eux était
  le meilleur moyen de rendre le collectif compétitif à l'intérieur.
- **Pas de mur de messages d'équipe.**
