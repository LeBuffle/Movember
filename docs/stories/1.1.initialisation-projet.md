# Story 1.1 : Initialisation du projet Next.js

## Status

Draft

## Story

**As a** développeur du projet,
**I want** un projet Next.js en TypeScript correctement configuré et outillé,
**so that** toutes les stories suivantes s'appuient sur un socle cohérent et vérifié.

## Acceptance Criteria

1. Le dépôt contient un projet Next.js 15 (App Router) en TypeScript, démarrant en local
   sans erreur ni avertissement bloquant.
2. Tailwind CSS est installé et fonctionnel.
3. ESLint et Prettier sont configurés, et une commande unique vérifie le formatage et le
   typage de l'ensemble du projet.
4. Vitest est installé, avec un test d'exemple qui passe.
5. Une page d'accueil provisoire affiche le nom du projet et la mention « application en
   construction ».
6. Une route `/api/health` renvoie un statut 200 avec la version applicative et
   l'horodatage.
7. Un fichier `.env.example` liste toutes les variables d'environnement attendues, **sans
   aucune valeur**.
8. Le `.gitignore` exclut `node_modules`, `.next`, et tout fichier `.env` autre que
   `.env.example`.
9. `README.md` décrit comment installer et démarrer le projet en local.

## Dev Notes

**Arborescence cible** (source : `docs/architecture.md` §7) — à créer progressivement, ne
pas tout échafauder ici :

```
src/
├── app/
│   ├── (public)/
│   ├── (participant)/
│   ├── (admin)/
│   └── api/
│       ├── webhooks/
│       └── cron/
├── components/
├── lib/
├── types/
└── styles/
tests/
```

**Version de Next.js :** 15.x, App Router. React 19. TypeScript 5.x.

**Variables d'environnement à déclarer dans `.env.example`** (noms seulement, valeurs
vides) : `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`,
`SUPABASE_SERVICE_ROLE_KEY`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`,
`NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`, `STRAVA_CLIENT_ID`, `STRAVA_CLIENT_SECRET`,
`STRAVA_WEBHOOK_VERIFY_TOKEN`, `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`,
`RESEND_API_KEY`, `CRON_SECRET`, `TOKEN_ENCRYPTION_KEY`, `NEXT_PUBLIC_SITE_URL`.

**Règle de sécurité impérative** (architecture §11) : **aucun secret dans le dépôt**.
`.env.example` ne contient que des noms de variables.

**Convention de langue** (`CLAUDE.md` §3) : le code, les noms de variables et les
commentaires techniques sont en **anglais**. L'interface utilisateur est en **français**.

**Ne pas faire dans cette story :** pas de charte graphique (story 1.5), pas de connexion
Supabase (story 1.6), pas d'authentification (story 1.7). Cette story livre un socle
technique nu.

### Testing

- Emplacement des tests : `tests/unit/` pour les tests unitaires, `tests/e2e/` pour
  Playwright (installé plus tard).
- Framework : **Vitest** pour l'unitaire.
- Test attendu ici : un test trivial vérifiant que la chaîne de test fonctionne, plus un
  test de la route `/api/health` renvoyant un statut 200.
