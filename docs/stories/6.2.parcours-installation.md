# Story 6.2 : Parcours d'installation guidé, distinct iPhone et Android

## Status

Draft

## Story

**As a** participant qui vient de s'inscrire,
**I want** qu'on me montre comment installer l'application sur mon téléphone,
**so that** je reçoive les notifications au lieu de les manquer.

## Acceptance Criteria

1. Le parcours affiche les instructions correspondant à l'appareil détecté : iPhone,
   Android, ordinateur.
2. Sur iPhone, il dit explicitement que **les notifications ne fonctionnent qu'une fois
   l'application ajoutée à l'écran d'accueil**.
3. L'installation est une **étape du parcours d'inscription**, pas une suggestion en
   passant.
4. Elle peut être sautée, et un rappel réapparaît pour les participants non installés.
5. Une application déjà installée ne propose plus rien.
6. Une détection ratée n'empêche pas de continuer : les instructions des autres appareils
   restent atteignables.

## Tasks / Subtasks

- [ ] Détection de l'appareil et instructions correspondantes (AC: 1, 6)
- [ ] Étape d'installation dans le parcours d'inscription (AC: 2, 3, 4)
- [ ] Détection du mode installé (AC: 5)
- [ ] Rappel aux non-installés (AC: 4)

## Dev Notes

**C'est le risque T5 du projet, et il n'est pas technique.** Sur iPhone, aucune
notification web n'existe hors application installée. Un taux d'installation faible se
paie en participants perdus en première semaine, et rien dans le code ne le rattrape.

**La détection se trompera.** Elle repose sur des indices de navigateur qui changent sans
prévenir ; les instructions des autres appareils doivent rester à un clic, sans quoi une
détection ratée devient un cul-de-sac.

### Testing

- Ouvrir le parcours sur iPhone (Safari), Android (Chrome) et ordinateur.
- Installer, rouvrir depuis l'écran d'accueil, vérifier que l'étape a disparu.
